## 📝 About This Repository
This repository contains **all lab assignments and projects** from the **Mobile Computing course**.  
All projects are built using **React Native** and **Expo**, focusing on **clean UI**, **efficient state management**, and **mobile-friendly design**.

> Each assignment has its **own folder**, containing source code, assets, and demos if available.

---

## 📂 Assignments Portfolio

### 🟢 Assignment 01 – To-Do List App
**Status:** ✅ Complete  
**Features from Code & Files:**  
- Add & delete goals using `useState`  
- Scrollable list using `FlatList`  
- Montserrat fonts via `@expo-google-fonts/montserrat`  
- KeyboardAvoidingView for better UX on mobile  
- Ionicons for "+" and trash icons  
- Card-style layout with custom colors  
- Mockup & Thumbnail images included (`todo_app_mockup.png`, `assignment01.png`)  
- Video demo stored inside project (`assignment01.mp4`)  
- Full report included (`Assignment 01 Report.pdf`)
